# 30-second jury demo (English)

Goal: anyone non-technical sees **real stellar motion** without a lecture.

## Script (≈30 s)

1. **(0–5 s)** Open the live site. Point at the title: *SPHEREx Explorer*.
2. **(5–12 s)** Barnard's Star is already selected. Press **Play movie** — “each frame is a different infrared color.”
3. **(12–22 s)** Press **Blink visits** (or key **B**). “Visit 1 vs Visit 3 — the star hops north; background stars stay put.”
4. **(22–28 s)** Tab **Show the move** (or **D**). “Bright/dark pair = it moved.”
5. **(28–30 s)** Hit **Fullscreen** (**F**) if projecting.

Backup line if someone asks “is this fake?”: “NASA SPHEREx sample cutouts; catalogue position is the orange cross.”
